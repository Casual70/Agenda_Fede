Come caricare un nuovo mese
  1. Clicca ⚙ Impostazioni e seleziona il file PDF del mese
  2. Clicca ⚙ Elabora PDF — il browser lo legge direttamente, nessun server necessario
  3. Verifica i turni mostrati a schermo
  4. Clicca 💾 Salva su Firebase per rendere i dati visibili online
Per modificare turni, orari o riunione d'équipe
  1. Clicca ✏ modifica sul giorno da cambiare
  2. Modifica operatori, orari o spunta la casella Riunione
  3. Clicca 💾 salva — i dati vengono aggiornati su Firebase

Seleziona il PDF e clicca Elabora — nessun server necessario.
