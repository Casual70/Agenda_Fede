====================================================
  AGENDA TURNI - COME AGGIUNGERE UN NUOVO MESE
====================================================

FLUSSO ATTUALE (aggiornato agosto 2026)
-----------------------------------------
Il parsing del PDF avviene direttamente nel browser (PDF.js).
NON serve più avviare il server locale né copiare il PDF nella cartella.


====================================================
  PROCEDURA COMPLETA PER UN NUOVO MESE
====================================================

PASSO 1 — APRI IL SITO
------------------------
Vai su:  https://casual70.github.io/Agenda_Fede/

Oppure in locale:  http://localhost:8080  (solo se il server è attivo)


PASSO 2 — IMPORTA IL PDF
--------------------------
1. Clicca  ⚙ Impostazioni  per aprire il pannello
2. Clicca il campo file e seleziona il PDF del mese
   es.  2608_TURNI AGOSTO 2026 - ORARIO.pdf
3. Clicca  ⚙ Elabora PDF
   → Il browser legge e interpreta il PDF senza server
   → I turni appaiono immediatamente a schermo
4. Verifica che tutti i giorni e gli operatori siano corretti


PASSO 3 — SALVA SU FIREBASE
-----------------------------
1. Clicca  🗑 Svuota mese corrente  (o 🗑 Svuota tutto se serve)
   → Conferma nel popup
2. Clicca  💾 Salva su Firebase
   → I dati vengono scritti su Firestore e visibili online


PASSO 4 — MODIFICHE MANUALI (se necessario)
---------------------------------------------
Per correggere un operatore, un orario o la Riunione d'équipe:

1. Clicca  ✏ modifica  sul giorno da cambiare
2. Modifica operatori (menu a tendina) e/o orari (campo di testo)
3. Spunta la casella "📋 Riunione d'équipe" se presente quel giorno
4. Clicca  💾 salva  → aggiornato su Firebase in tempo reale


PASSO 5 — AGGIORNA INDEX.HTML (opzionale, per dati di fallback)
-----------------------------------------------------------------
Solo se vuoi aggiornare i dati embedded in index.html (usati offline):

  python inject_data.py turni_maggio_2026.json turni_giugno_2026.json

Accetta più file JSON: li fonde e li inserisce in index.html.
Poi:
  git add index.html turni_MESE_2026.json
  git commit -m "Turni MESE 2026"
  git push


====================================================
  VISUALIZZAZIONE MULTI-MESE
====================================================
L'agenda supporta la visualizzazione di più mesi consecutivi.

Per mostrare due mesi insieme (es. maggio + giugno):
1. Elabora il PDF di maggio → Salva su Firebase
2. Elabora il PDF di giugno → Salva su Firebase
   (i mesi vengono fusi automaticamente, ordinati cronologicamente)

Ogni mese ha un banner separatore colorato.
Puoi rimuovere un mese singolo con  🗑 Svuota mese corrente
dopo aver elaborato il PDF di quel mese.

   → Aggiorna index.html con i nuovi dati embedded

     git commit -m "Turni agosto 2026"
     git push

5. Apri il sito e usa  💾 Salva su Firebase

====================================================
  PROCEDURA COMPLETA PER UN NUOVO MESE
====================================================

PASSO 1 — COPIA IL PDF
-----------------------
Copia il PDF del nuovo mese nella cartella del progetto:

  C:\Users\casua\Agenda_Fede\Agenda_Fede\

Esempio nome file: 2603_ TURNI MARZO 2026 - ORARIO.pdf


PASSO 2 — AVVIA IL SERVER LOCALE
----------------------------------
Apri PowerShell o CMD e lancia:

  cd C:\Users\casua\Agenda_Fede\Agenda_Fede
  python server.py

Vedrai:
  ==================================================
    Server Agenda Turni avviato!
    Apri: http://localhost:8080
  ==================================================

⚠️  Lascia questa finestra APERTA per tutta la durata del lavoro.
    Se la chiudi, il server si ferma e il browser non funziona.


PASSO 3 — APRI IL BROWSER
---------------------------
Vai su:  http://localhost:8080

Nella sezione "Importazione PDF" vedrai:
  🟢 Server locale attivo — puoi importare il PDF.

Se vedi 🔴, il server non è avviato → torna al Passo 2.


PASSO 4 — ELABORA IL PDF
--------------------------
  1. Nel campo di testo scrivi il nome esatto del PDF:
       es.  2603_ TURNI MARZO 2026 - ORARIO.pdf

  2. Clicca  ⚙ Elabora PDF
     → Il server legge il PDF, estrae i turni e aggiorna index.html
     → I dati appaiono subito a schermo

  3. Verifica che tutti i giorni del mese siano presenti e corretti.


PASSO 5 — SALVA SU FIREBASE
-----------------------------
  1. Clicca  🗑 Svuota DB  (per cancellare i dati del mese precedente)
     → Conferma nel popup

  2. Clicca  💾 Salva su Firebase
     → I dati vengono scritti su Firestore e saranno visibili
       anche dal sito pubblico su GitHub Pages.


PASSO 6 — AGGIORNA IL TITOLO (opzionale)
------------------------------------------
Se vuoi aggiornare l'intestazione "Mese di competenza: FEBBRAIO 2026":

  Apri index.html e cerca questa riga (circa riga 10):

    <p id="agenda-subtitle">Mese di competenza: FEBBRAIO 2026</p>

  Cambia il testo con il mese corretto, es.:

    <p id="agenda-subtitle">Mese di competenza: MARZO 2026</p>


PASSO 7 — PUBBLICA SU GITHUB
------------------------------
Dal terminale (con il server ancora aperto oppure in un secondo terminale):

  git add index.html
  git commit -m "Turni marzo 2026"
  git push

Il sito GitHub Pages si aggiorna entro 1-2 minuti.
Link: https://casual70.github.io/Agenda_Fede/

====================================================
  RISOLUZIONE PROBLEMI COMUNI
====================================================

ERRORE: "No module named 'flask'"
  → Stai usando il Python sbagliato.
  → Usa sempre:  python server.py  (non python3, non py)

ERRORE: "No module named 'pdfplumber'"
  → Reinstalla pdfplumber:
    python -m pip install pdfplumber

ERRORE 500 da /api/parse nel browser
  → Controlla che il nome del PDF sia scritto ESATTAMENTE
    come il file (maiuscole, spazi, underscore)
  → Controlla che il PDF sia nella cartella del progetto

ERRORE: "Connection refused" nel browser (🔴)
  → Il server non è avviato. Apri un terminale e lancia:
    python server.py

IL SITO GITHUB NON SI AGGIORNA
  → Aspetta 1-2 minuti dopo il push
  → Controlla su: https://github.com/Casual70/Agenda_Fede/actions
